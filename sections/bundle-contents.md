# Bundle contents

Bundle product page: the included-products grid and the value summary meter showing the total saving.

> **Tip:** Contents come from the product's `custom.bundle_products` metafield — see the Bundles guide.

**File:** `sections/bundle-contents.liquid` · Add anywhere via **Theme editor → Add section**.
