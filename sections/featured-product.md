# Featured product

A full buy-box for one product (price, rating, quick add) embedded in any page.

> **Tip:** Ideal for a single-product store's homepage — it's a real add-to-cart, not a link.

**File:** `sections/featured-product.liquid` · Add anywhere via **Theme editor → Add section**.

## Settings

| Setting | Type | Default | Notes |
| --- | --- | --- | --- |
| Product | `product` |  |  |
| Description override | `textarea` |  | Leave blank to use the product description. |
| **Secondary button** | | | |
| Label | `text` | Try the demo |  |
| Link | `url` |  | Leave blank to link to the product page. |
| Image ratio | `select` | 1 / 1 | Options: Square / Landscape (4:3) / Portrait (3:4) / Wide (16:10). |
| **Spacing & style** | | | |
| Top padding | `range` | 72 | 0–160 px. |
| Bottom padding | `range` | 72 | 0–160 px. |
| Section background | `select` | default | Options: Default (page background) / Subtle / Panel / Accent tint / Inverse (dark band). |
| Animate on scroll | `checkbox` | on | Fade/slide this section in. Requires Theme settings → Animations to be on. |
