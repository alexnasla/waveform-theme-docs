# Comparison table

A static feature-comparison table you fill in manually — great for plan tiers or you-vs-competitor matrices.

> **Tip:** Use `yes` / `no` in cells to render check and cross icons.

**File:** `sections/comparison-table.liquid` · Add anywhere via **Theme editor → Add section**.
