# Featured bundle

A wide promotional strip for one bundle with its savings called out.

> **Tip:** Works anywhere — home, collection pages, or under a product.

**File:** `sections/featured-bundle.liquid` · Add anywhere via **Theme editor → Add section**.

## Settings

| Setting | Type | Default | Notes |
| --- | --- | --- | --- |
| Bundle product | `product` |  |  |
| Heading | `text` | The entire catalogue, at the price of a few. |  |
| Text | `textarea` |  | Leave blank to use the product description. |
| Highlight badge | `text` | Best value |  |
| Secondary badge | `text` | Complete |  |
| Primary button label | `text` | Get everything |  |
| Secondary button label | `text` | See what's inside |  |
| Primary button link | `url` |  | Defaults to the bundle's page. |
| Secondary button link | `url` |  | Defaults to the bundle's page. |
| **Spacing & style** | | | |
| Section background | `select` | default | Options: Default (page background) / Subtle / Panel / Accent tint / Inverse (dark band). |
| Animate on scroll | `checkbox` | on | Fade/slide this section in. Requires Theme settings → Animations to be on. |
