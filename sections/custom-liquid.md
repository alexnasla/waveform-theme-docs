# Custom Liquid

Empty canvas for your own Liquid/HTML — escape hatch for anything the theme doesn't ship.

> **Tip:** Anything you can write in Liquid works here; styles from the theme's design tokens apply.

**File:** `sections/custom-liquid.liquid` · Add anywhere via **Theme editor → Add section**.

## Settings

| Setting | Type | Default | Notes |
| --- | --- | --- | --- |
| Liquid code | `liquid` |  | Add app snippets or any Liquid and HTML to create advanced customizations. |
