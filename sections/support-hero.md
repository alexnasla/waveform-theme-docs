# Support hero

Support page hero with live-filtering FAQ search.

> **Tip:** The search filters the FAQ section on the same page as the visitor types.

**File:** `sections/support-hero.liquid` · Add anywhere via **Theme editor → Add section**.

## Settings

| Setting | Type | Default | Notes |
| --- | --- | --- | --- |
| Eyebrow | `text` | Help centre |  |
| Heading | `text` | How can we help? |  |
| Subtext | `textarea` | Guides, answers and direct support for every … |  |
| Show FAQ search | `checkbox` | on | Filters the FAQ section on the same page as you type. |
| Search placeholder | `text` | Search the knowledge base… |  |
| Hint line | `text` | Try “install”, “license” or “refund” |  |
