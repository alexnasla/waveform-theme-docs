# Bundles hero

Hero for the bundles collection with gradient-emphasis heading and stat chips.

> **Tip:** Use the stat chips for totals like “4 bundles · save up to 40%”.

**File:** `sections/bundles-hero.liquid` · Add anywhere via **Theme editor → Add section**.

## Settings

| Setting | Type | Default | Notes |
| --- | --- | --- | --- |
| Eyebrow | `text` |  | Leave blank to use the collection title. |
| Heading | `inline_richtext` | Build your chain. <em>Pay for less of it.</em> | Italicized text renders in the accent gradient. |
| Text | `textarea` |  | Leave blank to use the collection description. |

## Block: Stat (`stat`)

| Setting | Type | Default | Notes |
| --- | --- | --- | --- |
| Number | `inline_richtext` | 7 | Italicized text renders in the accent gradient. Leave blank to show the live product count. |
| Label | `text` | Curated bundles |  |

_Maximum blocks: 4_
