# Logo list

A row of partner/press logos.

> **Tip:** Use monochrome transparent PNGs/SVGs at similar visual weight; they render dimmed for uniformity.

**File:** `sections/logo-list.liquid` · Add anywhere via **Theme editor → Add section**.
