# Spacer & divider

Adjustable vertical whitespace.

**File:** `sections/spacer.liquid` · Add anywhere via **Theme editor → Add section**.

## Settings

| Setting | Type | Default | Notes |
| --- | --- | --- | --- |
| Height | `range` | 40 | Scales down to 60% on mobile. 8–120 px. |
| Show hairline divider | `checkbox` | off | Adds a rule between two equal spacers. |
