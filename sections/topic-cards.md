# Topic cards

Support-page topic tiles linking to docs/pages.

**File:** `sections/topic-cards.liquid` · Add anywhere via **Theme editor → Add section**.

## Settings

| Setting | Type | Default | Notes |
| --- | --- | --- | --- |
| Heading | `text` | Browse by topic |  |
| Subtext | `text` | Jump straight to the area you need. |  |
| Top padding | `range` | 36 | 0–90 px. |
| Columns | `range` | 3 | 2–4. |
| **Spacing & style** | | | |
| Bottom padding | `range` | 72 | 0–160 px. |
| Section background | `select` | default | Options: Default (page background) / Subtle / Panel / Accent tint / Inverse (dark band). |
| Animate on scroll | `checkbox` | on | Fade/slide this section in. Requires Theme settings → Animations to be on. |
