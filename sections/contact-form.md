# Contact form

A styled contact form posting to Shopify's native contact form (replies go to your store email).

> **Tip:** Submissions arrive tagged so you can filter them in your inbox.

**File:** `sections/contact-form.liquid` · Add anywhere via **Theme editor → Add section**.

| Text | `textarea` | Bugs, billing, licensing or just advice on wh… |  |
| Status line | `text` | Support is online · avg. reply 4 hours |  |

| **Spacing & style** | | | |
