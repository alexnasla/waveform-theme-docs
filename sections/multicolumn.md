# Multicolumn

Simple 2–4 column text/icon layout for value props or how-it-works steps.

**File:** `sections/multicolumn.liquid` · Add anywhere via **Theme editor → Add section**.

## Settings

| Setting | Type | Default | Notes |
| --- | --- | --- | --- |
| Eyebrow | `text` | Why us |  |
| Heading | `text` | Everything you need, nothing you don't |  |
| Text | `textarea` |  |  |
| Columns on desktop | `range` | 4 | 2–4. |
| **Spacing & style** | | | |
| Content alignment | `select` | default | Options: Theme default / Left / Center. |
| Heading size | `select` | default | Options: Default / Small / Large / Extra large. |
| Top padding | `range` | 72 | 0–160 px. |
| Bottom padding | `range` | 72 | 0–160 px. |
