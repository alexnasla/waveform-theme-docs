# Bundle grid

Collection page grid purpose-built for bundles, with three savings display styles (badge, bar, or full price breakdown).

> **Tip:** Honest math: set each bundle's compare-at price to the exact sum of its parts.

**File:** `sections/bundle-grid.liquid` · Add anywhere via **Theme editor → Add section**.

## Settings

| Setting | Type | Default | Notes |
| --- | --- | --- | --- |
| **Toolbar** | | | |
| Show toolbar | `checkbox` | on |  |
| Toolbar title | `text` | All bundles |  |
| Toolbar hint | `text` | Every title is the full version |  |
| **Layout** | | | |
| View | `select` | grid | Options: Grid / List. |
| Grid density | `select` | three | Options: 3 per row / 2 per row. |
| Savings presentation | `select` | breakdown | Options: Badge / Value bar / Breakdown. |
| **Spacing & style** | | | |
| Section background | `select` | default | Options: Default (page background) / Subtle / Panel / Accent tint / Inverse (dark band). |
| Animate on scroll | `checkbox` | on | Fade/slide this section in. Requires Theme settings → Animations to be on. |
