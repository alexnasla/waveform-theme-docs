# Marquee strip

An infinitely scrolling text ticker.

> **Tip:** Short phrases separated by the divider glyph loop cleanly; respects reduced-motion.

**File:** `sections/marquee.liquid` · Add anywhere via **Theme editor → Add section**.

## Settings

| Setting | Type | Default | Notes |
| --- | --- | --- | --- |
| Loop duration | `range` | 26 | Lower is faster. The marquee pauses on hover and stops entirely for visitors who prefer reduced motion. 10–60 s. |
| Separator icon | `select` | spark | Options: Spark / Star / Lightning bolt / Waveform. |

## Block: Item (`item`)

| Setting | Type | Default | Notes |
| --- | --- | --- | --- |
| Text | `text` | Free updates |  |

_Maximum blocks: 10_
