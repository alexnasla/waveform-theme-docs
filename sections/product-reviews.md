# Product reviews

Star-rated customer reviews stored as metaobjects, with a moderated submission form.

> **Tip:** Requires the one-time metaobject setup — see the Reviews guide.

**File:** `sections/product-reviews.liquid` · Add anywhere via **Theme editor → Add section**.

## Settings

| Setting | Type | Default | Notes |
| --- | --- | --- | --- |
| **Displays entries from the "Product review (Waveform)" metaobject for this product. Submissions arrive as emails tagged product-review — approve them by adding an entry under Content > Metaobjects.** | | | |
| Eyebrow | `text` | From real sessions |  |
| Heading | `text` | Reviews |  |
| Reviews shown before "Show all" | `range` | 6 | 2–12. |
| **Spacing & style** | | | |
| Section background | `select` | default | Options: Default (page background) / Subtle / Panel / Accent tint / Inverse (dark band). |
| Animate on scroll | `checkbox` | on | Fade/slide this section in. Requires Theme settings → Animations to be on. |
